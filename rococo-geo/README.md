# Rococo Geo Microservice

Микросервис для управления географическими данными (страны) в системе Rococo.

## Описание

Этот микросервис выносит функциональность работы со странами из монолита в отдельный сервис. Он предоставляет REST API для управления странами.

## API Endpoints

### GET /api/countries
Получить список стран с пагинацией.

**Параметры:**
- `name` (опционально) - фильтр по названию страны
- `page` (по умолчанию 0) - номер страницы
- `size` (по умолчанию 10) - размер страницы

### GET /api/countries/name/{name}
Получить страну по названию.

### GET /api/countries/{id}
Получить страну по ID.

## Запуск

1. Убедитесь, что PostgreSQL запущен
2. Соберите проект: `./gradlew :rococo-geo:build`
3. Запустите: `./gradlew :rococo-geo:bootRun`

## Конфигурация

Порт по умолчанию: 8081

База данных: PostgreSQL
- URL: jdbc:postgresql://localhost:5432/rococo_geo
- Имя пользователя: postgres
- Пароль: postgres

## Интеграция с основным приложением

Основное приложение `rcc-api` теперь использует этот микросервис через `RestTemplate`. 
Локальные репозитории стран удалены из основного приложения.
